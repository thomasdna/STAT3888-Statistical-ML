# Team 15 — STAT3888 / NUTM3888

Reproducible analysis of the ABS **Australian Health Survey 2011–13** Basic
CURFs, covering both candidate directions the group has been comparing:

1. **Cardiometabolic health beyond BMI** (National Nutrition and Physical
   Activity Survey)
2. **Identifying unrecognised high cholesterol from non-laboratory information**
   (National Health Survey) — incorporating `STAT3888_Candidate_Q1.pdf`

This folder is meant to be pushed to git and shared with teammates. It contains
**all analysis code, all generated figures and tables, the literature PDFs, and
the candidate-question brief**. It does **not** contain the confidential CURF
CSVs; those stay on each teammate's machine (see [Data](#data)).

To run the analysis yourself in RStudio, use the sibling folder
[`../Git_reproducible_R`](../Git_reproducible_R) (open `Git_reproducible_R.Rproj`
and follow its README). That copy is set up so each `R/01`–`R/12` script can be
sourced from the project root.

Full write-up of methods and numbers: [`docs/ANALYSIS.md`](docs/ANALYSIS.md).

## Reproduce in three steps

Requires **R ≥ 4.3**. Tested on R 4.4.

```bash
# 1. Packages (once)
cd R
Rscript install_packages.R

# 2. Point at the course CURF CSVs (once)
cd ..
bash setup_data.sh

# 3. Rebuild everything
cd R
Rscript run_all.R
```

You do not need to rerun the pipeline to *read* the results: every figure and
table from the last successful run is already in `outputs/`.

Scripts can also be sourced one at a time from `R/`. They must be run in
numeric order the first time, because later scripts read files written by
earlier ones (`data/derived/` and `outputs/`).

**Runtime.** Scripts 01–07 and 10–11 take a few minutes. Script 08 (prediction
CV) and especially script 12 (4 outcomes × 5 models × 5 × 10-fold CV) take on
the order of **10–20 minutes** each.

### If `setup_data.sh` cannot find the CSVs

Either copy the course `all_files/*.csv` into `data/original_data/all_files/`,
or set:

```bash
export TEAM15_AHS_DATA="/path/to/STAT3888/data/original_data"
```

`00_setup.R` also looks automatically at `../data/original_data` so this folder
works if it stays inside `STAT3888/`.

## Two analyses, two surveys

Do not pool them. They do not share a sample.

| | NNPAS (`AHSnpa11b*`) | NHS (`AHSnhs11b*`) |
|---|---|---|
| Scripts | 03–09 | 10–12 |
| Theme | Cardiometabolic risk beyond BMI | Unrecognised high cholesterol |
| Extra variables | Diet, 24-hour recall | Smoking, exercise level, cholesterol testing |
| Biomedical adults 18+ | ~4,444 | 5,761 |
| Person key | `ABSPID` (unique) | `ABSLID` + `ABSPID` (`ABSPID` is **not** unique) |

The `inp13b*` files (Indigenous NPA Survey) are in the course dump and are
checked by script 02. They are not used in the models above.

## Headline results (for the team meeting)

### Candidate Q1 — unrecognised high cholesterol (scripts 10–12)

- The motivating “~89% of high cholesterol is unreported” figure **reproduces**
  (88.3%). It does not mean unaware: many people were told but say it is not
  current, and many who report it measure normal because they are on treatment.
- **RQ1 as written is negative.** Out-of-sample AUC for “high cholesterol, not
  self-reported” is 0.581 with age + sex and **0.576** with every non-laboratory
  predictor the proposal named. A full model finds 58.6% of cases vs **58.8%**
  for the existing “test everyone aged 45+” rule, at the same testing volume.
- BMI / waist help for **low HDL** (AUC 0.708; +25.8 pp over the age rule) and
  barely at all for total cholesterol. BMI beats waist on every outcome tested.
- **RQ2 is the stronger half.** At a fixed 40% flag rate almost nobody under 35
  is flagged and almost everybody over 65 is. Within age bands 55+ the model is
  worse than chance. It is weakest in the most disadvantaged areas (AUC 0.521).
- Higher BMI predicts **already having been tested** (OR 0.927 per kg/m² among
  adults 45+). Clinicians already triage on body size.

Self-reported high cholesterol in the NHS is **not** a person-level flag. It is
ICD-10 group `EVERCURF == 14693` in `AHSnhs11bcn`. Merging NHS files on
`ABSPID` alone will explode; use `ABSLID` + `ABSPID`.

### Cardiometabolic health beyond BMI (scripts 06–09)

- BMI category agrees only weakly with a 5-factor biomarker risk score.
- Age, BMI, smoking and self-rated health distinguish elevated risk; diet
  exposures do not (and that null survives a richer food-file definition).
- Extra diet / activity / SES blocks add about 13% of the predictive gain that
  BMI itself adds beyond age and sex.

Numbers, tables and caveats: [`docs/ANALYSIS.md`](docs/ANALYSIS.md).

## Pushing this to Git

From this folder:

```bash
git init
git add .
git status          # confirm no .csv unit-record files are staged
git commit -m "Team 15 STAT3888 analysis: code, outputs, and documentation"
```

Then add the GitHub remote your team agrees on and `git push -u origin main`.

`.gitignore` already excludes CURF CSVs and person-level derived files. Do not
force-add them.
